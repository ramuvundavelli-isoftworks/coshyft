# Coshift Mobile

## Prerequisites
- Node.js >= 18
- npm or yarn
- Expo Go app on your phone (optional)

## Getting Started

# 1. Clone the repo
git clone https://github.com/your-username/coshyft-mobile.git
cd coshyft-mobile

# 2. Install dependencies
npm install

# 3. Set up environment variables
cp .env.example .env
# Edit .env and fill in your values

# 4. Start the app
npx expo start

## Running on
- **Phone** → Scan QR code with Expo Go
- **Browser** → Press `w` in terminal
- **Android emulator** → Press `a`
- **iOS simulator** → Press `i` (Mac only)
